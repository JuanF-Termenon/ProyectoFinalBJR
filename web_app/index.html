ST Connect · Servicio Técnico

Gestión de incidencias técnicas

Plataforma centralizada para reportar, asignar y resolver incidencias técnicas desde cualquier puesto de trabajo. Rápido, trazable y seguro.

Explorar roles →
Arquitectura

Cuatro componentes,
un sistema unificado

La arquitectura separa responsabilidades con claridad: los clientes solo hablan con el backend, y únicamente el backend accede a la base de datos.

App de escritorio

Instalada en puestos fijos. Inicio automático, acceso rápido para reportar incidencias sin abrir navegador.

Aplicación web

Proximamente

Responsive. Acceso desde móvil, tablet u ordenador externo sin instalación previa.

Backend central

Autenticación, reglas de negocio, gestión de estados, exportaciones y auditoría. Único punto de acceso a la base de datos.

Base de datos

Almacena usuarios, puestos, incidencias, estados, históricos, informes, auditoría y configuraciones del sistema.

Usuarios y roles

Cada usuario, en su contexto

Sistema de permisos RBAC con cuatro niveles de acceso, adaptados al flujo real del servicio técnico.

Operario

Puesto de trabajo

Representa un área física como TP01 o Prensa04. Enfocado en la rapidez de reporte.

  • Iniciar sesión con usuario de puesto
  • Reportar incidencia con formulario mínimo
  • Descripción breve opcional
  • Ver estado de su última incidencia
Técnico ST

Técnico de Servicio Técnico

Cuenta personal por técnico. Gestión completa del ciclo de vida del ticket.

  • Ver y filtrar todas las incidencias
  • Asignarse y cambiar estados
  • Añadir notas internas
  • Cerrar con informe obligatorio
Jefe ST

Jefe de Servicio Técnico

Supervisión global del departamento. Acceso a métricas y exportaciones avanzadas.

  • Histórico completo de incidencias
  • Exportar por rango de fechas / filtros
  • Estadísticas por técnico y categoría
  • Rendimiento global del departamento
